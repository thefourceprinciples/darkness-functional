# Figures

This folder is reserved for generated figures and visual explanations.

The baseline simulation writes these files:

- `comparison_r.png` — coherence score over time.
- `comparison_D.png` — darkness load over time.
- `comparison_S.png` — persistence score over time.

To regenerate figures, run:

```bash
python src/darkness_simulation_package.py
```

Generated images should be treated as exploratory model output, not empirical proof.
