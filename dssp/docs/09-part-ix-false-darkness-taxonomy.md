# Part IX — False-Darkness Taxonomy

## 50. False darkness as a production chain

World -> interaction -> detector medium -> sensor -> electronics -> trigger -> storage -> calibration -> reconstruction -> selection -> statistics -> visualization -> interpretation -> publication -> institutional memory

A small defect introduced early may be transformed into a sophisticated anomaly later.

Example:

Temperature drift -> gain change -> energy shift -> threshold excess -> post hoc window -> apparent low-mass candidate

## 51. Family A — Instrument and apparatus artifacts

Major classes:

- saturation and nonlinear response;
- threshold pileup;
- electronic cross-talk;
- ground loops and power harmonics;
- mechanical microphonics;
- cryogenic boiling and phase instability;
- surface and wall events;
- charge trapping and delayed release;
- optical afterglow;
- magnetic hysteresis;
- vacuum outgassing and pressure bursts;
- cosmic activation;
- memory in materials.

Diagnostic principle:

The strongest artifact diagnosis is controlled reproduction.

Suspected pathway -> deliberate injection -> predicted detector response -> match to anomaly

## 52. Family B — Physical backgrounds

Major classes:

- radioactive decay;
- neutron background;
- solar, atmospheric, and diffuse neutrinos;
- cosmic-ray muons and secondaries;
- gamma rays;
- thermal and blackbody photons;
- radio-frequency interference;
- seismic and acoustic noise;
- atmospheric variation;
- solar and geomagnetic activity;
- astrophysical foregrounds;
- baryonic feedback;
- human and operational background.

A background is a real event with an incorrect or incomplete interpretation.

Background closure requires:

physical source + transport path + detector interaction + expected distribution + normalization + uncertainty + control behavior

## 59. Family I — Compound cascades

Threshold-drift cascade:

Temperature -> gain -> threshold -> excess -> selected window -> candidate

Shared-dependency cascade:

One flawed simulation -> many experiments use it -> classifiers inherit it -> outputs appear mutually confirming

Resonance cascade:

Mechanical mode -> electromagnetic pickup -> peak -> rescans -> apparatus persistence -> hidden-field story

Selection-significance cascade:

Many windows -> strongest selected -> local significance -> null windows omitted -> candidate narrative

Commercial-scale cascade:

Unexplained output -> premature transduction language -> funding and patents -> larger apparatus -> greater hazard while accounting remains open

Oracle cascade:

Ambiguous residual -> emotionally resonant symbolism -> selective evidence -> increased certainty

Imagination remains permitted. It must remain separated from evidential promotion.

## 60. Counterfeit-signal principle

For every proposed signature, DSSP constructs the strongest ordinary counterfeit.

Examples:

Axion-like peak:
RF injection, cavity crossing, thermal variation, digital clock leakage, mechanical resonance.

Nuclear-recoil excess:
Neutrons, surface events, threshold pileup, charge loss, neutrino recoils.

Missing momentum:
Detector gap, beam loss, misreconstruction, neutrinos, uninstrumented material.

Oscillating constant:
Temperature, magnetic field, timing error, power frequency, shared laser or clock noise.

Failure to counterfeit does not establish novelty. Successful counterfeit establishes non-uniqueness and a required discriminating test.

## 61. Repair and anti-erasure

Repair classes:

R1 = documentation repair

R2 = analytical repair

R3 = calibration repair

R4 = hardware repair

R5 = experimental redesign

R6 = institutional repair

R7 = semantic repair

A repair is complete only when:

Failure reproduced -> repair applied -> failure disappears -> valid injected signals remain recoverable -> regression test added

Original data and interpretations remain archived.
