# Executive Statement

The Dark-Sector Stewardship Project is a research and governance architecture for studying unexplained physical remainder without confusing uncertainty with possession.

Its purpose is not to begin with dark-matter harvesting, vacuum-energy extraction, gravity control, or a machine whose operating principle is already assumed. Its purpose is to build the evidential, computational, experimental, and ethical infrastructure required to determine:

- what was actually observed;
- which model produced the discrepancy;
- which uncertainties and backgrounds remain;
- whether the residual survives independent attempts at removal;
- whether a candidate mechanism produces prospective predictions;
- whether a measurable interface is causal, reversible, and bounded;
- whether energy, momentum, entropy, matter, and information ledgers close;
- and whether any resulting capability may responsibly be transferred, applied, scaled, or released.

The project’s foundational law is:

Unknown does not mean available.

The full DSSP sequence is:

Observe -> Preserve -> Explain -> Subtract -> Audit -> Classify -> Replicate -> Predict -> Couple -> Reverse -> Account -> Contain -> Apply -> Steward -> Release

No stage silently authorizes the next.

A residual is not a particle.

A candidate mechanism is not a discovery.

A discovery is not a controllable interface.

A controllable interface is not a safe application.

A safe application is not automatically fit to scale.
