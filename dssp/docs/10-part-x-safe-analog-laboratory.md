## 65. General hidden-state model

x_dot = A x + B u + G h + w

y = C x + D u + v

Where:

x = visible internal state

u = declared control input

h = concealed state or hidden forcing

y = measured output

w = process disturbance

v = measurement noise

Weakly coupled visible-hidden system:

x_dot = f(x, u) + epsilon K(x, z) + w_x

z_dot = g(z) + epsilon L(z, x) + w_z

y = H(x) + v

The analysis asks whether observations require hidden state z and nonzero coupling epsilon.

## 68. Key analog experiments

Weakly coupled mechanical oscillators:

Only the visible oscillator is measured. Hidden coupling may produce mode splitting, altered damping, beating, phase shift, or delayed energy exchange.

True coupling versus common driver:

Perturb oscillator A alone. If B responds as predicted, coupling gains support. If both only follow concealed H, correlation was not pairwise causation.

Weakly coupled resonant circuits:

Two low-voltage RLC systems test narrowband transfer, leakage, shielding, detuning, phase behavior, and independent readout.

Missing-energy analog:

A concealed capacitor, inductor, battery, thermal reservoir, or timing mismatch produces apparent excess until the full ledger closes.

Hidden thermal reservoir:

Post-shutdown rebound tests whether persistence represents stored energy rather than ongoing generation.

Hysteresis and apparatus memory:

Output depends on prior trajectory, showing how a model that forgets history can invent a hidden state.

Hidden optical modulation:

Weak periodic signals are challenged against aliasing, frame rate, power ripple, thermal lensing, vibration, and software processing.

Distributed sensor coherence:

The same apparent signal may originate physically at all sites, digitally after acquisition, through a shared clock, or from one common environmental source.

Adversarial causal illusion:

H -> A and H -> B can make A predict B even when A does not cause B. Intervention is required.

## 71. Reversibility protocol

R0 = baseline

Recovery error:

recovery_error(t) = |y(t) - y0|

Recovery time tau_R is the minimum time after shutdown at which the system remains inside the qualified baseline envelope.

Persistence classes:

## 72. Containment coordinates

Containment = spatial + temporal + energetic + informational + procedural

Spatial:
Effect remains where predicted.

Temporal:
Effect begins and ends inside a qualified interval.

Energetic:
Stored and released energy remain bounded.

Informational:
Hidden truth and controls do not leak into analysis.

Procedural:
Only authorized state changes occur.
