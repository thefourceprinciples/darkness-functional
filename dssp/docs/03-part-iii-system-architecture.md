# Part III — System Architecture

## 10. Five synchronized machines

DSSP operates through five coupled but non-collapsible systems.

Claim Machine:
Tracks what is being asserted, how it is scoped, what supports it, what contradicts it, and what state it may hold.

Evidence Machine:
Tracks observations, datasets, calibrations, simulations, replications, nulls, safety tests, and provenance.

Candidate Machine:
Tracks a proposed dark-matter, dark-energy, hidden-sector, modified-gravity, artifact, background, or ordinary-physics explanation.

Experiment Machine:
Tracks simulations, analog tests, detector runs, interface tests, containment tests, and application prototypes.

Gate Machine:
Determines whether an object passes, remains on hold, fails, enters quarantine, rolls back, retires, or releases.

## 11. Twelve-layer architecture

Layer 0 — Scientific Floor Registry

Maintains established observations, current constraints, reference models, open disputes, known backgrounds, and update dates.

Layer 1 — Provenance and Source Intake

Assigns persistent identifiers, version, authorship, access state, processing history, corrections, and integrity checks.

Layer 2 — Observation Normalization

Standardizes units, coordinates, timestamps, detector state, selection functions, uncertainty classes, and missing-data treatment without overwriting raw data.

Layer 3 — Darkness Functional Engine

Constructs raw and whitened residuals, persistence maps, spectral structure, cross-channel relations, model sensitivity, and residual topology.

Layer 4 — Model Basin

Maintains competing null, instrument, background, standard-physics, cosmological, modified-gravity, particle, hidden-sector, and empirical models.

Layer 5 — Artifact, Background, and Corruption Audit

Attempts to reproduce and remove false-darkness pathways before novelty advances.

Layer 6 — Candidate Interface Atlas

Maps candidates to couplings, observables, detectors, backgrounds, falsification conditions, current evidence, interface maturity, and stewardship restrictions.

Layer 7 — Synthetic and Analog Qualification Laboratory

Tests DSSP on systems whose hidden causes are known to designers but concealed from analysts.

Layer 8 — Controlled Interface Laboratory

Runs candidate-specific physical experiments only after evidence and interface gates pass.

Layer 9 — Accounting and Constraint Ledger

Tracks energy, momentum, entropy, heat, materials, cryogens, radiation, computation, rare resources, waste, and uncertainty debt.

Layer 10 — DMRC Adversarial Review

Preserves anonymous independent review, minority reports, disagreement, and strongest-counterfeit analysis.

Layer 11 — Stewardship and Release Gate

Controls continuation, exposure, transfer, publication, commercialization, scale, and decommissioning.

## 12. Canonical system flow

Source -> Observation -> Normalization -> Model Set -> Residual Family -> Artifact Audit -> Classification -> Prediction -> Replication -> Interface Test -> Accounting -> Stewardship Review -> Release

Every transition records:

- what changed;
- who or what changed it;
- assumptions introduced;
- evidence added or removed;
- contradictions remaining;
- gate decision;
- reason for advancement, restriction, rollback, or refusal.

A failed transition is retained as a scientific result.
