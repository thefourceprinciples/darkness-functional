# Version History

## v0.1.0 — Initial Public Research Scaffold

**Release date:** 2026-06-06

This release establishes the public scaffold for this systems framework as a companion project to Coherence Under Constraint (CUC).

### Included

- Cleaned top-level README.
- Clarified project status and scope.
- Added mathematical scaffold.
- Added research questions and initial predictions.
- Added citation metadata.
- Added paper, glossary, figure, and simulation scaffolds.

### Status

The framework is currently:

- conceptually drafted;
- mathematically scaffolded;
- connected to CUC;
- prepared for computational experimentation;
- not yet externally validated;
- not yet peer reviewed.
